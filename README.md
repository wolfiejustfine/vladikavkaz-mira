# Владикавказ — прогулка по проспекту Мира

[Играть в браузере](https://wolfiejustfine.github.io/vladikavkaz-mira/)

Трёхмерная прогулка по площади Ленина и проспекту Мира с вращающейся камерой, прохожими и трамваем. Трамвай останавливается, открывает двери и перевозит пассажира к следующей остановке. Звонок, двери и стук колёс учитывают расстояние до игрока.

Управление рассчитано на компьютер: WASD или стрелки — движение, Shift — бег, E — действие и трамвай, колесо мыши — масштаб, кнопки в правом верхнем углу — поворот камеры, Esc — пауза. В настройках можно изменить громкость и качество графики. Звук включается после начала прогулки.

Это собранная статическая версия приложения для GitHub Pages. Для локального просмотра запустите HTTP-сервер в корне репозитория; открытие через file:// не поддерживается.
