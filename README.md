# Владикавказ — прогулка по проспекту Мира

[**Играть в браузере**](https://wolfiejustfine.github.io/vladikavkaz-mira/)

Игра для компьютера с клавиатурой и мышью, без регистрации и установки. Старт — площадь Ленина. Стилизованные фасады, аллея, конструктор зданий, мини-карта и поездка на трамвае со звуком.

| Действие | Управление |
|---|---|
| Ходьба | WASD / стрелки |
| Бег | Shift |
| Осмотреть / сесть в трамвай / выйти | E |
| Заказать выход на следующей остановке | E во время движения |
| Сменить ракурс | Q |
| Вернуться на площадь | R |
| Масштаб | Колесо мыши / + / − |
| Пауза | Esc |

Звук запускается после первого нажатия. Кнопка звуков города выключает фон и эффекты. Сенсорное управление пока не реализовано.

## Локальный запуск

Это статический сайт на Canvas 2D, без npm-зависимостей. Запустите в этой папке HTTP-сервер, например: python -m http.server 8000. Откройте http://localhost:8000/ (открытие HTML через file:// не поддерживается).

## Публикация

GitHub Pages публикует корень ветки main. Изменения становятся доступны после успешного развёртывания Pages. .nojekyll отключает обработку Jekyll.

## Источники

Географические данные — © OpenStreetMap contributors, ODbL 1.0: GEODATA-LICENSE.txt и https://www.openstreetmap.org/copyright. Контуры и координаты распространяются в district.json и avenue-data.js. Архитектура и окружение — стилизованная реконструкция с оценочными деталями, не точная съёмка. Источники фасадов: facades.json; площади, аллеи и трамвая: файлы *-sources.json. Фотографии-референсы и изображения карт в игру не включены. Звуки синтезируются локально через Web Audio.

Публикация не устанавливает новую лицензию на авторский код и графику; лицензия ODbL относится к геоданным.
